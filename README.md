# 📊 DWBI Retail Sales Project

## 📌 Project Overview
This project demonstrates an end-to-end Data Warehouse & Business Intelligence (DWBI) solution.

The system simulates a retail company that collects data from multiple stores, processes it using ETL, stores it in a Data Warehouse, and visualizes insights using Power BI.

All data in this project is **synthetic (fake data)** generated using Python.

---

## 🧪 Data Generation

The dataset was fully generated by me using Python scripts.

- Random data was created using `pandas` and `numpy`
- Data includes customers, products, stores, and orders
- Daily transactional files were simulated for 50 stores

The scripts were executed using **Command Prompt**, which generated multiple CSV files used as input for the ETL process.

---

## 🏗️ Architecture

The project follows a classic DWBI pipeline:


Python (Data Generation)
↓
CSV Files
↓
Stage Layer (SQL Server)
↓
Data Warehouse (Dimensions & Fact Tables)
↓
Data Quality Checks
↓
Power BI Dashboard

---

## 🗄️ Data Warehouse Design

The Data Warehouse is built using a **Star Schema**:

### 🔹 Dimension Tables
- `DimDate`
- `DimCustomer`
- `DimProduct`
- `DimStore`
- `DimLoyaltyProgram`

### 🔹 Fact Table
- `FactOrders`

---

## ⚙️ ETL Process

The ETL pipeline includes:

- Loading CSV files using `BULK INSERT`
- Using Stage tables for raw data ingestion
- Transforming and loading data into dimension tables
- Loading transactional data into the fact table
- Handling both historical and daily incremental data (50 stores per day)

---

## 🧹 Data Quality Checks

After loading, the system performs validation and correction:

- Fix orders placed before store opening date
- Adjust customers under age 18
- Recalculate incorrect total amounts

---

## 📊 Power BI Dashboard

An interactive dashboard was built to analyze the data:

- 💰 Total Sales
- 📦 Total Orders
- 🛒 Total Quantity
- 📈 Sales Over Time
- 🏪 Sales by Store
- 🛍️ Top Products
- 🎛️ Filters by Date, Store, and Product
